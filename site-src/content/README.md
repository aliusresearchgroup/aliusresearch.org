## Legacy Source Archive

`site-src/content/` is now treated as legacy source material.

The active public site builds from:

- `site-src/sections/`
- `site-src/data/pages.json`
- `site-src/data/redirects.json`
- `site-src/static/`

This folder is intentionally kept for historical reference and future migration work, but it is no longer the primary source tree for the seven canonical site sections.
